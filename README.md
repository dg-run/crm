# CRM

Minimal open-source CRM starter under `dg-run` — public.

Built to complement [linkedin-analytics](https://github.com/dg-run/linkedin-analytics): turn post engagement + profile views into contacts, leads, and follow-ups.

## Quick start

```bash
npm install
npm run dev
```
